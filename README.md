# Agentic Commerce API Lab

Hands-on preparation repo for an **Agentic AI API Developer** role focused on commerce APIs, third-party integrations, orchestration, authentication/authorization, MCP tool exposure, and production readiness.

This repo is written as if Naresh is ramping into the Cincinnati Agentic Commerce pod. It connects prior resume strengths in REST APIs, OAuth/JWT, integrations, AI-assisted development, healthcare/finance-style enterprise constraints, telemetry, and production delivery to the job description.

## What You Will Build

- API-first commerce service with OpenAPI docs generated by FastAPI.
- Enterprise-style auth using bearer tokens, scopes, tenant context, and object-level checks.
- API orchestration layer that composes catalog, inventory, pricing, payment, and fulfillment partners.
- Adapter-based third-party integration pattern to avoid brittle point-to-point calls.
- MCP-style tool shim that exposes safe commerce operations to agents.
- Test suite covering deterministic behavior, integration contracts, authorization, idempotency, and agentic variability boundaries.
- Preparation docs for interview, onboarding, architecture, security, and learning resources.

## Quick Start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
uvicorn app.main:app --reload
```

Open:

- API docs: http://127.0.0.1:8000/docs
- Health: http://127.0.0.1:8000/health
- MCP tools manifest: http://127.0.0.1:8000/mcp/tools

Demo tokens:

- `Bearer partner-demo-token` has `orders:read orders:write tools:invoke`
- `Bearer analyst-demo-token` has `orders:read`

## Try The Core Flow

```bash
curl -s http://127.0.0.1:8000/health
curl -s -H "Authorization: Bearer partner-demo-token" http://127.0.0.1:8000/v1/catalog/products
curl -s -X POST http://127.0.0.1:8000/v1/orders/quote \
  -H "Authorization: Bearer partner-demo-token" \
  -H "Content-Type: application/json" \
  -d '{"customer_id":"cust_100","items":[{"sku":"sku-coffee-001","quantity":2}],"destination_zip":"45202"}'
```

## Why This Matches The JD

The job asks for someone who can build production-ready, partner-ready API capabilities for agentic commerce. This project demonstrates the full path:

1. REST APIs: versioned `/v1` endpoints with typed contracts.
2. Orchestration: quote and checkout flows compose multiple downstream services.
3. Auth: token validation, scopes, tenant boundaries, and object authorization.
4. MCP: tool definitions and invocation patterns for agent clients.
5. Third-party integrations: adapter interfaces with mock partner implementations.
6. Quality: tests for contracts, auth, idempotency, and non-deterministic agent inputs.
